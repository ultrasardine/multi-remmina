## Multi-Remmina - Multiplatform Remote Desktop Client

*Use other desktops remotely, from a tiny screen or large monitors - now on Linux, FreeBSD, and macOS.*

Multi-Remmina is a multiplatform port of the popular Remmina remote desktop client, extending support beyond Linux to FreeBSD and macOS while maintaining full protocol compatibility.

* RDP, VNC, SPICE, X2Go, SSH, WWW (HTTP protocol) and EXEC network protocols are supported.
* Written in GTK with cross-platform compatibility.
* Released as "multi-remmina" (the main program) and "multi-remmina-plugins".

### Installation

#### Linux
Follow the standard build instructions in the wiki.

#### macOS
See [macOS Build Instructions](docs/MACOS_BUILD.md) for detailed setup.

#### FreeBSD
Standard CMake build process with FreeBSD-specific paths.

### Configuration

Set up everything from the graphical interface, or from $HOME/.config/multi-remmina
